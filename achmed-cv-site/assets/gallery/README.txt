Put your flyers, posters, thumbnails and other designs in this folder.

Name them:  design-1.jpg, design-2.jpg, design-3.jpg, design-4.jpg, design-5.jpg, design-6.jpg

- Use .jpg (or change the file names in index.html if you use .png).
- Portrait images (4:5, e.g. 1080x1350) look best.
- Any image that is missing is hidden automatically, so you can add just one or two.
- Change the captions in index.html (search for "figcaption").
